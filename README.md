# WeatherCast 🌦️

A modern and responsive weather prediction web application built using React, TypeScript, and Vite.

## Features

- 🌍 Search weather information by city
- 🌡️ Display current temperature
- ☁️ Show weather conditions and descriptions
- 💧 Display humidity
- 💨 Show wind speed
- 👁️ Display visibility
- 📊 Show atmospheric pressure
- 🌅 Show sunrise and sunset times
- 🇮🇳 Support for Indian and Nepali cities
- 📱 Fully responsive design

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Lucide React


## Installation

Clone the repository:

git clone https://github.com/Gautamdutta-star/Weatherprediction.git

Navigate to the project folder:

cd Weatherprediction

Install dependencies:

npm install

Run the development server:

npm run dev
